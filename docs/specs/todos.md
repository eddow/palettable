# Ideas for after the first release

The [publication roadmap](publication.md) tracks the work needed for the first release.

## Additional generic types

- Color
- Range
- Vector (at least two dimensions)
- Breadcrumbs

## Editing and controls

- Add an edit-mode context menu for tools and toolbars. Decide whether tracks also need one.
- Allow tools to be resized along their axis, including sliders in drawers.
- Let the mouse wheel change a slider's value while the pointer is over it.
